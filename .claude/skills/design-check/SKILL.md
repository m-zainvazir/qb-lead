# design-check (stub: filled in as modules land)

1. Ask which module (or read the one in progress from `docs/plans/module-NN-*.md`).
2. Read the module plan's "System design checks" and the "System design" and "Easy to miss" lists in `docs/plans/00-overview.md`.
3. For each item, find evidence in the code (file:line) or mark it as a gap.
4. Report a table: check | status (ok / gap / n/a) | evidence or what is missing.
